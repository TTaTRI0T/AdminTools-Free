# Modero Lite

![Version](https://img.shields.io/badge/version-3.0.0-blue)
![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-green)
![License](https://img.shields.io/badge/license-MIT-lightgrey)

**AdminTools Lite** — бесплатный и легковесный плагин для модерации Minecraft-серверов (Paper/Spigot 1.21.1+).  
Содержит всё необходимое для управления нарушениями: кики, баны, муты, предупреждения, удобное GUI, фильтр чата и поддержку PlaceholderAPI.

---

## 🚀 Возможности
- ✅ **Кик / Бан / TempBan / Разбан / Мут / Размут / Варн** с настраиваемыми причинами
- ✅ **Гибкая система предупреждений** (действия на определённых порогах: 3 варна → мут, 5 → темпбан, 10 → перманентный бан)
- ✅ **Проверка истории игрока** — `/check <игрок>`
- ✅ **Чат для персонала** — `/staffchat`
- ✅ **Удобное GUI-меню** — `/adminmenu`
- ✅ **Tab‑подсказки** для всех команд
- ✅ **Фильтр чата** с автоматическим мутом за запрещённые слова
- ✅ **Оффлайн‑наказания** — игрок получает наказание, даже если не в сети
- ✅ **Авто‑снятие наказаний** по истечении срока
- ✅ **Логирование** всех действий в файл
- ✅ **PlaceholderAPI** — плейсхолдеры `%admintools_warns%`, `%admintools_muted%`, `%admintools_banned%`

---

## 📦 Установка
1. Скачай последний `.jar` со [страницы релизов](https://github.com/yourusername/AdminToolsLite/releases)
2. Помести его в папку `plugins/` твоего сервера
3. Перезапусти сервер
4. Настрой `plugins/AdminToolsLite/config.yml`
5. *(Опционально)* Установи [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) для работы плейсхолдеров

## 🆓 Lite vs Full
Это бесплатная **Lite-версия** AdminTools.  
Полная версия включает **ScreenCheck, Vanish, Reports, Discord‑embed, расширенный фильтр, статистику персонала** и другие премиум-функции.  
При обновлении до Full-версии все данные сохраняются!
